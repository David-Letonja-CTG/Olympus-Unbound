# Spec Delta

## MODIFIED Requirements

### Requirement: Main menu
Opening the game SHALL show the main menu with the actions Play, Progression, Settings and Intro, after the intro on first launch. Every visible action SHALL work; the menu SHALL be operable with mouse and keyboard.

#### Scenario: First visit
- **WHEN** the player opens the game for the first time and the intro ends or is skipped
- **THEN** the main menu shows Play, Progression, Settings and Intro and the player's gold (0)

#### Scenario: Keyboard navigation
- **WHEN** the player tabs to Play and presses Enter
- **THEN** god selection opens
