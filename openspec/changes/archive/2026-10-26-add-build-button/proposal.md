# Proposal

## Why

The owner could not find the build panel on a computer (2026-10-26). On a phone a hexagon button opens it. On a computer only Tab does, and neither the Settings controls nor the main menu's key hints mention Tab.

## What Changes

- **A build button on the computer HUD:** the same hexagon as on a phone, above the ability slot, labelled with its key (Tab). One click opens the build panel; the panel's close button or Tab closes it.
- **Controls listed:** Settings lists "Your build: Tab or the ⬡ button · Back / Select", and the main menu's key hints add "Tab for your build".

## Capabilities

### Modified Capabilities

- `hud`: the build panel opens from a HUD button with a mouse, too.

## Non-goals

- A button for every player at a shared screen: they keep Tab and their gamepads' Back/Select.
